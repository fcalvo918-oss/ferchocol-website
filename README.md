# Ferchocol Software website
Static GitHub Pages-ready starter site.

Before publishing:
1. Review all copy.
2. Replace the starter privacy text with the final reviewed policy.
3. Confirm the public email address.
4. Commit these files to the GitHub Pages repository.
5. Point `ferchocol.com` to GitHub Pages only when ready.

Tagline: **Building simple. Solving real problems.**

## Search-engine verification

The verified Google Search Console tag is in the production homepage `<head>`. If Bing later requires an HTML meta tag, add the real `msvalidate.01` tag beside the Google tag; do not add a placeholder code.

IndexNow is not enabled. Enabling it requires a real IndexNow key, a root-level `<key>.txt` verification file containing that key, and authenticated URL-submission requests. Review that implementation before adding it.
